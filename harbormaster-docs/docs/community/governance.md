# Governance

This page says who maintains Harbormaster and how decisions are made. It is for contributors and users who want to know how the project is run.

## Maintainers

Harbormaster is maintained by RCSS Labs. The maintainers review and merge changes, cut releases and decide the direction of the project. Maintainers are listed on the repository at <https://github.com/rcss-labs/harbormaster>.

## How decisions are made

- Day-to-day changes are decided in pull request review. A maintainer approves and merges.
- Larger changes are discussed in an issue first. The maintainers aim to reach agreement in that thread. When they cannot, the maintainers make the final decision and explain it.
- Changes that affect security, permissions, data migrations or the Terraform interface get extra scrutiny and may need documentation and upgrade notes before they merge.
- The `main` branch is the supported line. See [Reporting vulnerabilities](../security/reporting-vulnerabilities.md).

## Becoming a maintainer

Contributors who make sustained, high-quality contributions and follow the [code of conduct](code-of-conduct.md) may be invited to become maintainers by the existing maintainers.

## Changes to this page

This document may change as the project grows. Proposals go through the same issue and pull request process as any other change.
